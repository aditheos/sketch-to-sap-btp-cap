Mermaid syntax tips

Node shapes:

  • A[Label] — rectangle (most services)
  • A[(Label)] — cylinder → database hint (HANA, Object Store)
  • A(Label) — rounded rectangle
  • A{Label} — rhombus / decision

Edges:

  • A --> B — plain arrow
  • A -->|REST API| B — arrow with label
  • A -.-> B — dotted (converted to solid arrow)
  • A --> B --> C — chained edges
